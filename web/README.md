# vm2api 门面前端

简体中文的深色资源工作台。页面包括公开商品、认证、用户总览、订阅续费、账号详情、OAuth 托管向导、密钥与接入示例、用量、订单，以及管理员的全部八个工作区。

## 安装与验证

需要 Node.js 22.12+ 和 pnpm 10。

```bash
cd web
pnpm install
pnpm exec tsc --noEmit
pnpm build
```

产物为 `web/dist/`。请由同源 Web 服务托管，并将非 `/api`、`/v1` 静态路径回退到 `index.html`，保证嵌套路由可以直接打开。Vite 的基础路径为 `/`。

## 技术选择

使用 React 19、TypeScript strict、Vite 7、Tailwind CSS 4、TanStack Query、React Router 7、Recharts、Sonner，以及自行实现的 shadcn 风格 UI 组件。选择 React Router：本项目路由规模明确，以嵌套布局组合登录与管理员守卫直观，且不需要额外生成路由文件。用户页和管理页按路由延迟加载。

请求统一在 `src/lib/api.ts` 中发送，遵守 `docs/PORTAL_API.md`：Cookie 会话、JSON 信封、写请求 JSON、错误提示和未授权跳转。API 路径与页面同源；`base_url` 为空时使用 `location.origin`。金额以整数分计算并转人民币展示，上游费用独立按美元展示，时间在展示时转浏览器本地时区。

## 开发演示

仅 Vite 开发模式默认启用内存 mock，生产构建剔除 mock 模块。开发时设置 `VITE_MOCK=false` 可使用真实同源 API；本次验收未启动开发服务或调用真实后端。

- 默认演示会话为管理员。右上角与侧栏标记「演示模式」。
- 管理员：`demo@vm2api.local`；普通用户：`user@vm2api.local`；密码均为 `demo123456`。
- 所有业务数据仅驻留内存，刷新后重置；`sessionStorage` 仅保存模拟用户 ID。密钥明文不持久化，只在创建响应中返回一次。
- 托管授权输入 `demo-code-123456` 可完成流程，输入 `bootstrap-fail-demo` 可演示初装失败后重试。演示链接不连接真实授权服务。
- 商品购买选择「模拟支付」，可体验支付后自动履约与订单轮询。人工转账说明明确无需真实转账。
- mock 保留空用量、重新授权、暂停、失败等状态，覆盖完整管理操作；未知接口返回明确错误。

## 接口边界

授权进度每 2 秒轮询，正常账号用量每 30 秒刷新；支付和履约完成后停止订单轮询。OAuth 链接提示 30 分钟过期，支持重新生成与失败重试，复制授权码后仅提交官方 OAuth 交换入口。

订单支付参数来自创建响应并通过路由状态传入详情页。契约未定义重新获取支付参数接口；直接打开旧的待支付订单时会提示查看原支付窗口或联系管理员，仍持续查询真实订单状态。管理员设置的支付密钥返回 `***` 时提交会保留原值，留空同样保留。

未实现真实付款、授权服务、邮件或任何额外后端接口。管理员资源释放、停用用户、删除密钥等操作在提交前均显示确认弹窗。界面支持键盘焦点、原生对话框、移动导航、减少动态效果偏好，以及加载、空数据和错误重试状态。
