# 前端交付记录

## 实现范围

仅修改 `web/`。采用 React Router 7 的嵌套路由，在共享布局外验证登录，在管理路由再次验证 `role=admin`；普通用户导航隐藏管理入口。主要页面按路由拆包，图表独立拆包。

| 区域 | 页面与交互 |
| --- | --- |
| 公开 | 品牌落地页、三类商品价格与库存、数量与支付方式弹窗、登录、注册开关 |
| 总览 | 总并发与在途、托管席位、租赁权益、今日用量、到期提醒、统一地址复制、账号动态 |
| 订阅 | 有效／过期筛选、来源订单、按可续费商品发起续费 |
| 账号 | 类型筛选、备注、脱敏邮箱、套餐与语义状态、5h／7d 环形额度及倒计时、窗口花费、席位占用 |
| 账号详情 | 30 天柱状趋势、模型表、今日与窗口统计、备注修改、移除确认 |
| 托管向导 | 建槽 → 官方 OAuth 链接 → 粘贴授权码 → 初装 → 完成；2 秒轮询、链接过期、重新生成与失败重试 |
| API 密钥 | 创建后只展示一次明文、复制、启停与删除确认、单密钥统计、三种客户端示例 |
| 用量 | 7／14／30 天及自定义本地日期区间、每日趋势、模型／密钥／账号分布、日志筛选与分页 |
| 订单 | 列表与详情、四种支付展示、取消、支付后轮询至终态、资源刷新 |
| 安全 | 修改密码、撤销其他会话的说明 |
| 管理后台 | 仪表盘、商品增改上下架、订单确认收款与重履约、用户停用与赠送订阅、订阅调整、VM 候选入池和健康维护、资源重试与强制释放、任务重试、完整设置表单 |

请求封装集中于 `src/lib/api.ts`；写请求即使无参数也发送 JSON `{}`。金额以分计算并转元展示，上游费用单独展示美元，时间统一转浏览器本地时区。全局 Sonner 提示、加载／空数据／错误重试、渲染异常边界、原生模态框焦点、移动导航与减少动画偏好均已实现。

## 后续集成边界

真实后端、付款和 OAuth 没有联调；生产部署应将 SPA 路由回退至 `index.html` 并同源提供 `/api`、`/v1`。支付参数仅存在创建订单的响应中，直接访问没有支付参数的旧待付订单会明确提示查看原支付窗口或联系管理员；没有新增契约外接口。

开发内存数据刷新重置，只有模拟用户 ID 存于 sessionStorage；密钥明文不持久化。演示账号、密码和授权码使用方式见 `README.md`。
